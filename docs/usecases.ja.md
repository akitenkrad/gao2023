# ユースケース

本プロジェクトでできることと，詳細ドキュメントへの導線．

## 1. 単一 S³ シミュレーションの実行

有向フォローグラフ上で LLM エージェントを駆動し，集団レベル伝播の創発を観察する．

```bash
cargo run --release -- run --network ba --population 100 --rounds 20 --seed 42
uv run s3-tools visualize
```

全フラグは [CLI](cli.ja.md)，図は [可視化](visualization.ja.md) を参照．

## 2. 実行のコスト 0 再現 (キャッシュ決定論)

ウォーム `.llm_cache/` で **同一** コマンドを再実行すると，同一 LLM 応答が再生され (cache-hit ≈ 100%)，決定論的コアが bit 安定かつ高速になる．実行内容の確認:

```bash
uv run s3-tools show-experiment-settings --results-dir results/latest
```

[アーキテクチャ › 二層決定論](architecture.ja.md#二層決定論) を参照．

## 3. オフライン検証 (ライブ LLM 不要)

Ollama/OpenAI の無いサンドボックスや CI で，mock 駆動スモークとテストを実行する．

```bash
cargo test                                   # mock 駆動; ライブ LLM 不要
cargo run --release --example mock_smoke -- results
uv run s3-tools visualize
```

mock (`socsim-llm::mock::ScriptedClient`) はスクリプト化された感情/態度/行動決定を返し，パイプライン全体 (配送 → 知覚 → 伝染 → 指標 → CSV/JSON) を駆動する．

## 4. 感度分析 (network × population)

ネットワーク種別と人口規模を走査し，トポロジと規模が伝播へ与える影響を見る．

```bash
cargo run --release -- sweep --network er,ws,ba --population-values 50,100,200 --rounds 20 --runs 3 --seed 42
uv run s3-tools visualize-sweep
```

期待 (定性的): BA (スケールフリー) はハブ経由で情報が最速で拡散し，人口規模が大きいほど集団レベル割合が安定する．

## 5. 拡張 (Phase 3 フック)
