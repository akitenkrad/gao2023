# Use cases

What you can do with this project, and where to read more.

## 1. Run a single S³ simulation

Drive LLM agents on a directed follow-graph and watch population-level propagation emerge.

```bash
cargo run --release -- run --network ba --population 100 --rounds 20 --seed 42
uv run s3-tools visualize
```

See [CLI](cli.md) for every flag and [Visualization](visualization.md) for the figures.

## 2. Reproduce a run for free (cache-determinism)

Re-running the **same** command with a warm `.llm_cache/` replays identical LLM responses (cache-hit ≈ 100%), so the run is fast and bit-stable in the deterministic core. Inspect what a run talked to:

```bash
uv run s3-tools show-experiment-settings --results-dir results/latest
```

See [Architecture › Two-layer determinism](architecture.md#two-layer-determinism).

## 3. Offline verification (no live LLM)

In a sandbox or CI without Ollama/OpenAI, run the mock-driven smoke and the test suite:

```bash
cargo test                                   # mock-driven; no live LLM
cargo run --release --example mock_smoke -- results
uv run s3-tools visualize
```

The mock (`socsim-llm::mock::ScriptedClient`) returns scripted emotion/attitude/behavior decisions, exercising the full pipeline (delivery → perception → contagion → metrics → CSV/JSON).

## 4. Sensitivity analysis (network × population)

Sweep the network kind and population size to see how topology and scale shape propagation:

```bash
cargo run --release -- sweep --network er,ws,ba --population-values 50,100,200 --rounds 20 --runs 3 --seed 42
uv run s3-tools visualize-sweep
```

Expectation (qualitative): BA (scale-free) spreads information fastest via hubs; larger populations stabilise the population-level fractions.

## 5. Reproduce the headline result and compare against classical baselines

Run S³ once, check its propagation observables against the paper's qualitative bands, and compare against the four classical diffusion / opinion-dynamics baselines on the same directed graph:

```bash
# Offline (no live LLM): a scripted mock client reproduces the pipeline end-to-end
cargo run --release -- reproduce --mock --quick --seed 42
uv run s3-tools reproduce --results-dir results/latest
```

`reproduce_summary.json` records the observed-vs-paper checks (attitude rise, cascade growth, behavior adoption, an emotion-distribution MSED proxy, an attitude Pearson-correlation proxy) with PASS / off verdicts, plus the LT / IC / Voter / DeGroot comparison. Run a single baseline on its own with `cargo run -- baseline --model {lt|ic|voter|degroot}`.

## 6. LLM-driven perception

By default the perception step ranks messages with a deterministic rule-based influence score (zero LLM calls). Pass `--llm-perception` to instead have the LLM rank the candidate messages:

```bash
cargo run --release -- run --network ba --population 20 --rounds 3 --seed 42 --llm-perception
```

The LLM-driven path shares the contagion call's client and cache and falls back to the rule-based score if the LLM returns no usable indices. The initial-attitude LLM prompt is also provided in `prompts.rs` for further extension.
